## 今回の構成

- 入力：保存された実画像1枚と、台座・肩・肘・グリップの指令角度。工程ラベル・YOLO検出座標は使わない。
- 出力：4関節の絶対目標指令角度を、0.2秒刻みで最大8時刻分。最初の目標は観測時刻から0.2秒後、最長1.6秒後。
- 画像：160×120。ImageNet事前学習済みResNet-18を凍結し、4×5×512の空間特徴をキャッシュ。特徴の射影とTransformerは学習する。
- Transformer：幅128、4ヘッド、FF次元512。CVAE事後分布エンコーダー、観測統合エンコーダー、操作デコーダーは各2層。
- 潜在変数：32次元。学習時は事後分布からサンプリング、推論時はz=0。
- 損失：有効要素の平均L1＋10×KL。パディングは事後分布エンコーダーとL1から除外。
- AdamW、学習率0.0001、weight decay 0.0001、勾配ノルム上限1、乱数シード42、CPU 2スレッド。
- 関節と操作の正規化統計は学習分割だけから計算。標準偏差の下限1°。
- 検証時は実行時と同じz=0で評価し、そのMAEが最小の重みを保存。

原著の4カメラ・14次元・画像480×640・Transformer幅512等から縮小し、画像バックボーンも凍結した**動作確認用の独自実装**。原著者のコードをそのまま実行したものではない。Temporal Ensemblingと実機の制御ループは今回は未実装。

参照：[原論文](https://arxiv.org/abs/2304.13705)、[公式モデル](https://github.com/tonyzhaozh/act/blob/main/detr/models/detr_vae.py)、[公式損失](https://github.com/tonyzhaozh/act/blob/main/policy.py)。

## 元記録からの変換

元の画像・episode.json・samples.jsonlは変更しない。全27試行のsamples.jsonlについて、開始前後のSHA-256一致を確認した。

- 受理されたjog操作だけを利用。旧ステップ方式の2試行と、混在した旧操作等は対象外。
- 指令送信時刻を基準とする実画像を使用。画像の古さが0〜0.25秒のものだけを採用。欠けた画像は生成しない。
- 操作区間内では、記録された操作前後の**指令角度**を線形補間する。実際のサーボ運動を復元したものではない。
- 前の操作区間終了から次の送信までが0.35秒を超える場合は系列を分割。短い間隔では前の終了指令を保持したと仮定する。
- 0.2秒刻みの未来の正解を取り出す。系列末尾より先はマスクし、少なくとも2時刻分の正解がある入力だけを使う。
- 入力画像自体は元の操作ごとの撮影時刻のまま。連続した5Hz動画へ変換したものではない。
- 分割の試行IDは既存MLPのreport.jsonに従う。ただし、採用サンプル・入力・出力が違うため、既存MLPの数値との直接比較はしない。

紙やアームの映り方なども含む現在の保存画像を使用。画像が動作判断に十分使われたか、未見の配置で搬送できるかは未確認。

## 再実行

依存関係が揃った現在の環境で、プロジェクトルートから実行する。

別環境でResNet重みがまだない場合は、次の公式重みを取得する。生の実演データは別途必要。

```bash
mkdir -p models
curl --fail --location --output models/resnet18-f37072fd.pth \
  https://download.pytorch.org/models/resnet18-f37072fd.pth
```

```bash
uv run --no-sync python vision/act_smoke.py --steps 200
```

既に保存されたResNetの特徴を再利用し、新しく学習する。今回の結果を残したまま別の実行をする場合は、`--output runs/act_smoke_another` など別の出力先を指定する。

保存した重みを読み込み、未使用試行の元画像1枚から操作列を予測する：

```bash
uv run --no-sync python vision/infer_act_smoke.py \
  --episode 20261031T013236_735561Z \
  --index 2
```

このコマンドは予測値を表示・保存するだけで、基板やカメラに接続しない。

```bash
uv run --no-sync python -m unittest discover -s tests -p test_act_smoke.py
```

確認済み：長い空白を越えて正解列を生成しないこと、指令補間、パディングによる事後分布・損失の不変性、有限な勾配、z=0推論の再現性。学習コード内でも保存重みの再読込による予測一致を確認する。
