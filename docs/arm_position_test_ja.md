# 紙面の座標を指定する最初の実機テスト

11点から推定したモデルで角度候補を計算し、まず1か所だけ確認する。全11点の取り直しは行わない。高さは計算上0mm、手首80度、グリッパー150度（閉じた先端の中心）。

## 起動

既存のアーム操作サーバー（8765）は終了しない。映像付き画面のプロセス `vision/arm_camera_panel.py` が動いていれば、そのターミナルだけCtrl+Cで終了し、更新版を起動する。

```bash
.venv-ai/bin/python vision/arm_camera_panel.py
```

ブラウザで <http://127.0.0.1:8766> を開き、再読み込みする。起動・読み込み・候補計算では接続、保持解除、移動の指令は送らない。アーム操作サーバーが起動していない場合は起動時にエラーとなる。モデルが未生成の場合は座標欄が表示されない。

## 最初の1か所

1. 青枠と紙の格子が一致していること、試す場所と移動中の範囲にスポンジ・ターゲット・ケーブルなどがないことを確認する。
2. 「紙面座標から角度を試す」で、初期値 **X=15、Y=135mm** のまま「角度候補を計算」を押す。目標に橙の十字が表示される。
3. 候補は台座・肩・肘の順に **93、144、63度**。手首80度、グリッパー150度を保つ。
4. 各「候補へ1°近づける」を押し、映像と実機を見ながら少しずつ近づける。1クリックで1関節だけ1度動き、連続自動移動はしない。全関節が保持・静止している場合に使える。手首・グリッパーが条件と違う場合は既存の操作欄で合わせる。
5. 机への接触や無理な姿勢が見えたら、その先へ進めない。高さ0の計算は机との干渉を保証しない。
6. 候補角度まで到達し、実機が静止したら確認欄にチェックし、「状態と写真を保存」を押す。メモには見えたずれの方向などを残せる。

実機の現在角度が前回の記録と違う場合、開始姿勢からの経路は別に確認する。一括で候補角度へ飛ばす操作は追加していない。表示角度は指令値で、実測角度ではない。

## 保存内容

`runs/arm_position_tests/日時/` に以下を保存する。

- `raw.png`：カメラの新しい元画像。
- `marked.png`：青枠・紙面目標の十字・撮影時指令値入り画像。
- `record.json`：目標XYZ、計算候補、モデルのハッシュ、撮影時刻、撮影前後の状態、メモ。

撮影前後の指令が違う、候補角度に未到達、無保持・移動中の場合は保存を拒否する。写真の十字は紙上の目標であり、実際の先端位置ではない。実測誤差の値を自動では付けない。

## 次へ進む判断

この1点で大きな位置ずれや接触がないか確認してから、スポンジの位置へ候補を計算する。持ち上げ高さ・開いたグリッパーでの把持位置・搬送経路は、この平面テストとは別に確認する。

コードとルートのテストは模擬サーバー／合成画像で実施。実機の移動とブラウザ上の操作は未実施。
