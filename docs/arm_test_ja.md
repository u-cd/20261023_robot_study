# 5関節を別々に操作する手動テスト

`firmware/arm_test/arm_test.ino` を使用。基板起動時は全サーボの信号を停止し、STARTで指定した関節だけを有効にします。別の関節をSTARTしても、すでに有効な関節は指令を保持します。

| 番号 | 部位 | 接続先 |
| --- | --- | --- |
| 1 | 台座 | Servo1 / D9 |
| 2 | 肩 | Servo2 / D6 |
| 3 | 肘 | Servo3 / D5 |
| 4 | 手首 | Servo4 / D3 |
| 5 | グリッパー | Servo5 / D11 |

## 準備・給電

USBと電池を外して配線を行います。現在の単体テストコードが起動しないよう、まずサーボを外して新コードを書き込み、USBを抜いてからServo1〜5へ接続します。起動直後は全関節が無保持なので、アームを可動域を妨げない方法で支持してください。

USBでの単体試験成功は5個同時の電力を保証しません。複数関節を保持・動作させる前に、基板に適合するサーボ電源とUSB併用方法を確認してください。適合する電源が未確認なら、ケーブルを1個ずつつなぎ替えても、この同じコードでテストできます。電源不足によるリセットは全関節の信号停止と落下につながります。

## 直接コマンド

シリアルモニタをCtrl+Cで終了し、プロジェクトルートで実行：

```bash
.tools/arduino-cli compile \
  --fqbn arduino:avr:uno \
  --libraries /home/u/.arduino15/libraries \
  --build-path "$PWD/.build/arm_test" \
  firmware/arm_test

.tools/arduino-cli upload \
  --fqbn arduino:avr:uno \
  --port /dev/ttyUSB0 \
  --input-dir "$PWD/.build/arm_test" \
  firmware/arm_test

.tools/arduino-cli monitor --port /dev/ttyUSB0 --config baudrate=115200
```

モニタ接続によって基板がリセットされると、すべての信号がOFFになります。重力のかかる関節を支持してから接続します。

## 操作コマンド（大文字、Enterで送信）

| 入力例 | 動作 |
| --- | --- |
| `START 1 90` | 台座を有効にして90度を指令 |
| `MOVE 1 100` | 台座の目標を100度へ変更 |
| `START 4 90` | 手首も有効にし90度を指令 |
| `MOVE 4 95` | 手首だけを95度へ移動。台座は保持 |
| `STATUS` | 各関節の有効状態・指令値・目標値を表示 |
| `STOP` | 全関節の目標を直前の指令値に変更し、移動指令の更新を止める。保持は継続 |
| `OFF 4` | 手首への信号を停止。サーボ電源自体は切らない |
| `HELP` | コマンド一覧 |

MOVEの初期速度は40msごとに指令角度を1度変更する約25度/秒です。`SPEED 2 50` のように関節番号と度/秒を指定すれば、関節ごとに5〜100度/秒の範囲で変更できます。速度変更は移動目標を解除し、変更だけでは移動しません。再起動で25度/秒に戻ります。実際の速度や角度は測定していません。STARTでは現在の角度が分からないため、最初の動きを速度制限できません。確認済みの初期値を使い、初回はアームを安定させて試します。

## 0〜180度の意味

関節1〜4は0〜180度、グリッパー（関節5）は暫定50〜150度の指令を受け付けます。STARTとMOVEの両方に制限が適用され、範囲外の指令は拒否されます。STATUSで設定範囲を表示します。これは機構の安全な範囲や実際の180度回転を保証しません。いきなり0度・180度へ動かす自動テストはありません。

2026年10月25日のユーザーによる実機報告で、グリッパーの可動範囲は指令値約50〜150度でした。公式サンプルの35〜90度とは異なるため、取り付け状態を含めたこの実機の観察値を暫定設定に使います。端の50度・150度を連続使用できるという保証ではありません。通常の試験は端から余裕を取り、例えば55〜145度の内側から確認してください。他関節も小さく範囲を広げ、接触する前に止めます。物をつかませず試し、異音、たわみ、過熱、再起動があれば電源を切ります。

関節2・3は一部の姿勢で動作不良が報告されています。安全な範囲は未確定で、0〜180度は入力上限にすぎません。ケーブルの干渉、電源の電圧降下、姿勢による負荷を切り分け、動ける角度を記録してからMIN_ANGLES/MAX_ANGLESを狭めます。ケーブルには関節付近の余裕を残し、絡み・引っ張りを避けます。MOVEの速度は40ms/度を維持します。

STOPは機械的な停止や電源遮断ではありません。停止後も直前の指令位置に向かって実際の軸が動くことがあり、初回STARTの急な動きも防げません。電源遮断やOFFで肩・肘の保持が失われるため、落下にも備えます。

指令値の記録を元に、各関節の初期角度と使用可能範囲を決めていきます。現在は未校正のテスト段階で、起動時に自動で姿勢をそろえる処理はありません。
