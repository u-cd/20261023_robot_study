# 再起動後の模倣学習テスト再開

2026年10月31日。再起動後に再開し、学習・評価・実機1°試行まで完了した。[最新の結果](imitation_first_evaluation_ja.md)を参照。以下は再実行手順。

## 学習を再開

プロジェクト直下で実行する。

```bash
uv run python vision/train_imitation.py
```

成功デモの保存画像からYOLO11nの検出特徴を生成し、既存の有効なfeatures.jsonは再利用する。試行単位で学習・検証・テストへ分割し、15入力→64→64の小さなMLPで操作方向9クラスと角度変化量を学習する。CPUは2スレッド。学習の選択は検証用試行の損失で行い、テスト試行は選択に使用しない。

学習完了後に `runs/imitation_bc/policy.pt`、`report.json`、`predictions.json`、`viewer.html` を生成する。viewer.htmlで未使用試行の画像・教師操作・予測を確認できる。実データでの学習完走を確認済み。

## 実機用の画面

別々のターミナルで起動する。

```bash
uv run python control/arm_panel.py --record-calibration
```

```bash
uv run python vision/arm_camera_panel.py
```

<http://127.0.0.1:8766> を開く。追加した「学習済みAIの試行」では、段階を選んで予測を表示し、明示的なボタン操作で1°の試行ができる。予測表示だけでは動かない。モデル完成前は利用できない。段階の切替は手動であり、完全自律搬送を実装・確認した状態ではない。

全5関節を有効にし、手首80°に揃えて使用する。初期有効化の角度は現物の姿勢に合わせる。モデルの信頼度・カメラの更新・姿勢の変化・学習範囲を確認してから1°だけ送信する。実際の物理的成功率は今後確認する。

## 再開時の確認事項

- 特徴抽出が全成功試行で完了するか。
- 学習が完走し、試行単位の評価指標を保存できるか。
- 現行モデルと単純な最近傍の基準を比較する。
- 学習した角度量は連続区間ごとに異なるので、一律1°の教師とは扱わない。
- 学習出力の次操作精度と、実機での把持・搬送成功は別に評価する。
