# 比較基準として残す既存MLP

初回実験：2026年10月31日。現在の小型ACTと入出力・採用サンプルが異なるため、以下の数値をACTと直接比較しない。

## 学習

- 成功27試行を試行単位で学習19・検証4・テスト4へ分割。seed 42。
- サンプル数：学習3,315、検証573、テスト646。
- 入力15個：スポンジ・coinの中心座標4、信頼度2、検出有無2、4関節の指令角度、3段階のone-hot。
- MLP：15→64 ReLU→64 ReLU→操作9クラスと角度変化の絶対値。
- AdamW、学習率0.001、weight decay 0.001、バッチ128。
- 損失：交差エントロピー＋0.5×SmoothL1（絶対角度変化量÷4）。
- 最大300 epoch、検証損失で選択、改善しない状態が60 epoch続くと終了。74 epoch実行し、最良は14 epoch。

## 結果

| 指標 | 結果 |
|---|---:|
| 未使用試行の操作一致率 | 52.48% |
| 最近傍基準の操作一致率 | 47.37% |
| 多数派基準の操作一致率 | 14.71% |
| 角度変化量の絶対値のMAE | 約0.678° |

操作一致率は搬送成功率ではない。手動で段階を選ぶモデルで、停止の正解例が不足している。以前の実機試行では台座ばかりを選ぶ問題があり、台座目標や順序の補助ルールも試した。それらの旧ルールと実行UIはACT中心の整理で削除し、純粋なMLPの学習・予測コードと評価結果を残す。
